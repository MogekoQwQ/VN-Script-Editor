# VN Script Editor

一个本地优先的视觉小说脚本文本编辑器，适合写作、整理、校对和导出 Ren'Py 脚本片段。

在线地址：

[打开在线编辑器](https://mogekoqwq.github.io/VN-Script-Editor/)

## 主要功能

- 结构化脚本编辑：左侧说话人，右侧正文内容
- 支持 `#1` 到 `#4` 四级标题及章节折叠
- 支持旁白、角色台词、备注行
- 角色映射、导出 ID 和说话人颜色
- gutter 点击、拖拽或 Shift 点击选择连续行范围
- 上方行工具条统一提供剪切、复制、在下方粘贴和删除
- Menu 分支标记、整体折叠及结构校验
- 标题、Menu 和全部选项的目录导航与独立折叠
- 阅读宽度、编辑区字号设置及小窗口自适应布局
- 从纯文本插入，支持匹配规则及说话人确认
- 查找替换、撤销和重做
- 自动保存到浏览器本地
- 项目文件导入 / 导出
- Ren'Py 片段导出
- PDF 阅读稿预览导出
- PWA 安装支持

## 本地运行

```bash
npm install
npm run dev
```

开发服务器启动后，在浏览器中打开 Vite 提供的本地地址即可。

## 构建

```bash
npm run build
```

构建产物输出到：

```text
dist/
```

## 静态部署

这是纯前端静态应用，可以直接部署到：

- GitHub Pages
- Cloudflare Pages
- Netlify
- Vercel

基础流程：

```bash
npm install
npm run build
```

然后把 `dist/` 部署到静态托管平台即可。

## GitHub Pages

当前仓库已经配置 GitHub Pages Actions 自动部署。

如果你要在自己的仓库里复用：

1. 修改 `vite.config.ts` 中的 `BASE_PATH`，使 Vite、PWA 启动路径、作用域和图标路径保持一致。
2. 子路径部署使用仓库名；根路径部署使用 `/`。例如：

```ts
const BASE_PATH = "/your-repo-name/"
```

3. 在仓库设置中打开：
   `Settings` -> `Pages` -> `Build and deployment` -> `Source: GitHub Actions`

## 安装为桌面应用

部署到网页后，用户可以在支持 PWA 的浏览器中选择“安装应用”或“添加到桌面”。

安装后通常可以从以下入口启动：

- 桌面图标
- 开始菜单
- 应用启动器

脚本文本默认保存在当前浏览器本地存储中。重要项目请定期导出 `.vns` 项目文件备份。

## 数据保存与备份

- 脚本文本默认保存在当前浏览器本地存储中
- 刷新页面后，应用会优先恢复最近一次自动保存的项目
- 清理浏览器数据、切换浏览器或使用无痕模式，可能导致自动保存丢失
- 重要项目请使用右侧“保存”面板导出 `.vns` 项目文件备份

## 项目文件说明

- 项目文件包含完整项目数据：脚本行、角色映射、设置和元信息
- 可通过“导入项目文件”恢复编辑状态
- 导入会覆盖当前内容，导入前会要求确认
- 文件名使用项目名称和时间戳，文件内容为 JSON；同时兼容旧的 `.vns.json` 和 `.json` 项目文件
- 新建空白项目或重置示例项目也会替换当前内容，请先备份

## 编辑与行范围操作

- `Enter` 在当前行下方新增行并聚焦说话人；正文内 `Shift + Enter` 输入换行
- `Tab` 和 `Shift + Tab` 均在同一行的说话人与正文之间切换
- 点击行左侧 gutter 选择单行，拖拽或 Shift 点击扩展连续范围
- 编辑输入框时隐藏行工具条，复制、剪切和粘贴保持原生文字操作
- 脚本层复制保留行结构；粘贴插入到当前范围的文档顺序最后一行下方
- 外部纯文本在脚本层粘贴时整体生成一条旁白；需要拆行或识别说话人时使用“从纯文本插入”

## Menu 与章节折叠

在说话人栏填写完整标记，内容栏填写对应文字：

| 说话人 | 内容 | 含义 |
| --- | --- | --- |
| `#menu` | 选项提示文本，可为空 | 开始 Menu |
| `#option` | 选项一 | 开始第一个选项 |
| 作者 | 此台词属于选项一。 | 选项内剧情 |
| `#option` | 选项二 | 开始第二个选项 |
| 助手 | 此台词属于选项二。 | 选项内剧情 |
| `#endmenu` | 留空 | 结束 Menu，内容栏禁用 |
| 留空 | 此行属于共通内容。 | Menu 后的旁白 |

Menu 不支持嵌套、条件选项或自动生成 label、jump。保留标记不参与角色映射与自动补全。

正文中的小箭头可收起完整 Menu 或标题章节。标题范围截止于下一个同级或更高级标题之前，没有后续标题时延续至文档末尾。父章节展开后保留子级折叠状态。

目录折叠与正文折叠独立；点击隐藏节点会展开正文中必要的祖先区块并定位。折叠状态只属于界面，不写入项目文件、不进入撤销栈，也不影响导出。范围操作涉及隐藏内容时，会先展开并提示确认范围。

## Ren'Py 导出说明

- Ren'Py 导出生成的是脚本片段，不等于完整 Ren'Py 工程
- 角色台词会根据右侧角色映射中的导出 ID 转换
- 备注和标题可按设置导出为注释
- Menu 自动生成 `menu:`、选项及四空格缩进，角色 ID 仍来自角色映射
- 结构错误会阻止导出并提示行号；无可执行剧情的选项会提示并补充 `pass`

## PDF 阅读稿说明

- PDF 功能会打开一个可打印的阅读稿预览页
- 在预览页顶部点击“打印 / 保存为 PDF”，再使用浏览器打印对话框保存为 PDF
- 这更适合试读和校对，不是完整排版出版功能

## 浏览器兼容性

- 推荐使用最新版 Chrome、Edge 或其他现代 Chromium 浏览器
- 功能依赖 `localStorage`、Clipboard API、打印能力、Service Worker 和现代表单控件

## 隐私说明

- 当前版本没有后端服务，脚本文本不会主动上传
- 默认数据只保存在当前浏览器本地
- 如需长期保存或跨设备继续编辑，请自行导出项目文件备份
